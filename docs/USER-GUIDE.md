# 按时、按季吃水果：操作手册

本工具帮助回答“这个月可以关注哪些水果、哪些产区、什么风味”。数据来自维护者导入的主表和补充资料，季节会受天气、栽培方式和储藏影响。

## 一次完整使用

1. 启动后在电脑浏览器打开首页。选择当前月份；「全部」表示全年资料。
2. 先看「本月尝鲜」，或者选水果类目、省份，输入产品名或产地关键词。
3. 想找脆爽、酸甜或浓香的水果时使用口味筛选；「有口味资料」只保留已补充描述的记录。
4. 点击省级气泡，联动筛选产区。数字是当前筛选结果的记录数，不是产量、果园数或价格。
5. 打开水果卡片，查看上市月份、月份状态、品种、风味描述和资料适用范围，再点来源核对。
6. 清空筛选可重新探索；拖动、加减号调整地图，复位恢复默认位置，「完整全国视图」查看全貌。

## 怎样读资料

| 状态 / 字段 | 应怎样理解 |
| --- | --- |
| 月份已核验 | 主表明确标记已经核验；仍须留意适用产区和年份 |
| 月份有来源 | 有可追溯依据，未自动升级为人工核验 |
| 月份估算 | 参考范围，不能当作当地当年的实际采收结论 |
| 月份待补 | 没有可用月份；指定月份筛选时不会作为当季结果 |
| 产区代表品种 | 介绍当地常见品种，不等于当前记录已明确到该品种 |
| 品种共性口味 | 文献中的定性描述，不是这批水果的甜度或口感保证 |
| 空白字段 | 暂无足够资料；不会根据水果类目自动编造口味 |

产地展示最细到乡镇；原资料只有村名且无法确定乡镇时，退到有依据的县级。跨省或范围不明的关联可以继续出现在列表中，但可能没有归入某个省级气泡，页面会提示待归属数量。

## 数据和使用范围

公开源码不带数据库；首次运行空库需要自行导入。截图演示的是维护者本地实例，不保证当前月份都有相同结果。

目前没有购买链接、果园预约、价格、库存、营养评价或手机适配。地图气泡是省级汇总位置，不是具体果园坐标。使用自己的来源资料后，可依照 [数据管理说明](DATA-MANAGEMENT.md) 更新内容。
